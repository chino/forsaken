# Forsaken

This repo holds the community port of Forsaken!

Check out the [Wiki](https://github.com/ForsakenX/forsaken/wiki) for more information.

## Music

The soundtrack (originally CD audio) is played from Ogg Vorbis, FLAC or WAV
files that you put in `data/sound/music/`, for example the Ogg tracks from
Forsaken Remastered or your own CD rip. See [docs/music.md](docs/music.md).
